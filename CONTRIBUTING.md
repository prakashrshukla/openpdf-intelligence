# Contributing

Thanks for helping improve OpenPDF Intelligence.

1. Open an issue describing the problem or proposed feature.
2. Create a focused branch and add/update tests.
3. Run `pytest` and `ruff check .`.
4. Do not commit PDFs containing private data, `.env` files, credentials, or model weights.
5. Keep third-party model terms and dependencies documented.
6. Submit a pull request with a clear summary and testing notes.

Please avoid claiming OCR correctness without a reproducible test corpus and documented evaluation method.
